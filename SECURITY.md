# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue or pull request. Use GitHub's
private vulnerability reporting for this repository when it is available. If private reporting is
not enabled, contact a repository maintainer through GitHub and ask for a private reporting
channel. Include the affected version or commit, the impact, and steps to reproduce. Avoid sharing
real credentials or other sensitive user data in the report.

## Response and disclosure

Maintainers aim to acknowledge a report within five business days and provide an initial
assessment within ten business days. We will coordinate a fix and public disclosure with the
reporter. Please allow maintainers a reasonable opportunity to investigate and release a fix
before disclosing a vulnerability publicly.

Security fixes will be identified in the relevant release notes. Supported versions, if any, will
be stated there; users should upgrade to the latest supported release when a fix is available.
